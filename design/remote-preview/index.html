The APK, and the right-click door that pairs it

An interactive mock of both halves of SALU Remote, built from remote.md (the PC side) and remote_apk_ui.md (the APK). Right-click the picture to open the strip — Remote is the new rightmost seat (D9) — then click it for the QR panel. On the phone, the Connect sheet scans it. After that the two mockups drive each other: transport, seek, volume, the Player / Web switch, and tapping a file in Browse plays it on the PC. The QR is a real, scannable code for the real pairing payload.

Nothing here is Flutter — it is a review artifact, wired to no lib/ code.

The socket, as it would actually read

Every line is a message from remote.md §6 — one JSON object per WebSocket frame. Commands are fire-and-forget; state is always a full snapshot, never a diff (D5). Watch it while you press things.

What to look at

ThingDecision it demonstrates
Remote, rightmost in the stripD9 — the QR door is the last item, after Settings. Widths go 162 → 198 (full canvas) and 82 → 118 (channel list), per remote.md §5.3.
The strip closes before the panel opensThe same _door() every other item uses — one popup at a time.
QR on a white cardA dark code on dark glass scans badly. 12 px quiet zone, pure black modules, no animation. The payload is a salu:// URI so any camera app can read it.
The code rotates on closeA5 — close the panel and reopen it: a new code. A QR photographed over a shoulder stops working.
The mode switch shows both seatsNot one pill that toggles — Player and Web are both on screen, on the phone header and in the toolbar above. Pick either and the other side follows.
Web mode shrinks the remoteDead buttons make an app feel broken, so the transport rows disappear and the page's own player takes over.
Browse greys out in Web modeOpening a PC file pulls the PC straight back to Player mode (D8), so the tab would only ever bounce you. Tapping it says why instead of failing quietly — and switching to Web moves you off it.
Tune becomes a D-pad in Web modeNo equalizer, no subtitles, no audio track — mpv is not in the picture. What is left is a page to get around: ▲▼ walk the focus, ◀▶ are history, OK clicks.
The PC draws a ring on the focused elementThe part that makes the D-pad usable at all. With no visible focus the phone is steering the browser blind.
web_key is a new verbremote.md §17.4 has browser_nav and the web_media_* family but nothing that moves focus. The side keys reuse browser_nav; the arrows and OK need web_key {key} added to the spec.
Volume changes show nothing on the PCA1 — remote commands raise an OSD card except volume and mute; you are already looking at your phone.
Browse → Files, tap a rowThe file never travels. The phone sends a path, the PC opens it locally — a 40 GB file costs one message.
Settings → Remote toggleD10, default ON. Off tears the listener down: the port frees, Show pairing code disables, and the phone drops.
Tune says "Nothing is playing"EQ, subtitles and audio are meaningless with no media — the tab says so in one place instead of showing dead sliders.
