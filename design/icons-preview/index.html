SALU · design preview — no implementation

Icon family proposals & colour concepts

Plus four colourful app-icon concepts built from the double-loop + play mark. Hover any mark to feel the recipe.

4 · Colourful SALU app-icon concepts

The double-loop + play mark keeps its geometry; colour is the variable. All four sit on the same dark tile so the jump from today's monochrome icon is easy to judge. UI marks stay monochrome either way — colour lives only in the identity.
Tide
Blue→teal back loop, alive-green front loop. Colour pulled from the app's own accent + statusAlive.
Dusk
Violet→magenta over blue→cyan — an evening-screen mood, still cool like the UI.
Ember
Warm coral→amber — the boldest option; reads like a projector lamp on a dark wall.
Signal (quiet)
Today's monochrome mark, with only the loop terminals lit in the app accent — smallest possible step into colour.
Small sizes
Tide at 48 / 32 / 24 / 16 — dots drop out first, loops stay legible
