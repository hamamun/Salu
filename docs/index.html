Design & Capabilities

What only SALU does

Every choice avoids visual clutter — monochrome marks, zero printed shortcut hints at rest, instant undo instead of confirmation popups.

Stop parks the queue

Stop clears the screen and saves your exact timestamp. Press Play and SALU resumes right from that second — Stop is not Start Over.

32 px Mini Bar

Shrinks the entire player into a 488 × 32 px always-on-top floating strip with a top-edge seek line, volume wheel, and title-swap feedback.

10-band EQ & Auto Tone

13 audio presets, 4 video presets, picture looks, aspect stops, speed 0.5×–3×, and per-file Auto EQ memory loaded before the first frame.

50k+ M3U Channels

Incremental parser handles massive IPTV playlists off the UI thread, inferring Category, Country, and Language even from bare streams.

QR Phone Remote

Built-in LAN WebSocket server (port 7258) pairs once via QR code with byte-paged channel browsing and zero cloud accounts.

Subtitles & Synced Lyrics

OpenSubtitles hash & text search with auto-download, native libass rendering, ±5s per-file subtitle offset, and .lrc click-to-seek lyrics.

Built-in Web Browser

Uses Windows’ own Edge WebView2 runtime with lazy tabs, 15 bookmarks, Save-As downloads, pop-up control, and live keep-alive.

Living Map & Alt-Peek

Standard mpv/VLC/Edge keys stay invisible at rest. Hold Alt to peek keychips or test keys live on a miniature player inside Settings.

Four-continuum tuning

SALU tunes EQ, Picture Looks (Original, Vivid, Night, Faded, Warm, Cool), Aspect Ratio stops, and Speed on one shared continuum model — blending smoothly between presets and remembering curves per file.

Zero-cap incremental M3U8 parsing

Playlists opened from local files or direct URLs are parsed incrementally by SALU itself — never dumped raw into mpv. Even bare playlists without tags infer Country and Language from tvg-id, prefixes, or stream queries.

  • Grouping modes: Flat · Category · Country · Language
  • Provider favourites: survive credential rotations without storing raw stream URLs
  • 3-strike dead-channel skip: automatically advances past unreachable streams
  • Clean live timeline: still soft indicator light inside the controller

media_kit + libmpv-2.dll Hardware-accelerated playback (d3d11va), native libass subtitle rendering, audio filters.

Get SALU

Build on Windows & share the project

Open-source Flutter desktop codebase with one-command Inno Setup packaging.

Build & package from source

  • Windows 10 (1809+) or Windows 11 (x64)
  • Flutter SDK 3.47.5 (Dart ≥ 3.4.0) & Visual Studio 2022 C++ Desktop workload
  • Optional: Inno Setup 6 (ISCC.exe) to generate dist\SALU-Setup-0.1.0.exe
git clone https://github.com/hamamun/Salu.git
cd Salu
flutter pub get
flutter run -d windows

# Clean rebuild + standalone Windows installer
powershell -ExecutionPolicy Bypass -File tools\build_installer.ps1
